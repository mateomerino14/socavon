SOCAVÓN, una historia del Cerro Rico de Potosí
Versión 0.4.0 para Windows (64 bits)

Para jugar, abre Socavon.exe. No hace falta instalar nada.
Usa audífonos: gran parte del miedo está en el sonido.

Controles
  Moverse ................. W A S D
  Mirar ................... Ratón
  Correr .................. Shift
  Agacharse ............... Ctrl o C
  Lámpara ................. F (encender o apagar), rueda del ratón (llama), R (recargar carburo)
  Usar .................... E (recoger, ofrendar, leer, esconderse y salir)
  Lanzar una piedra ....... Clic izquierdo
  Escuchar ................ Mantener clic derecho
  Asomarse ................ Q y Z
  Pausa ................... Esc

La partida se guarda sola al empezar cada nivel y cada vez que le pides permiso al Tío en un altar.
Windows puede avisar que el programa no está firmado; elige "Más información" y luego "Ejecutar de todas formas".
